# Implement an issue

Read `AGENTS.md`, `.agents/project.yaml` and `.agents/registry.yaml`.

Select one primary role and the appropriate workflow. Then:

1. Summarize the objective and acceptance criteria.
2. State assumptions, risks and protected areas.
3. List the minimum files expected to change.
4. Inspect existing patterns before implementing.
5. Make surgical changes only.
6. Run the relevant commands from `.agents/project.yaml`.
7. Return a concise summary, verification evidence, risks and anything not tested.

Do not invent project commands, architecture or requirements. Mark missing information explicitly.
