# Feature workflow

1. Restate objective, exclusions and acceptance criteria.
2. Inspect the nearest existing implementation pattern.
3. Select one primary role from `.agents/registry.yaml`.
4. Plan the smallest vertical slice and list files to touch.
5. Implement without unrelated refactors.
6. Add tests for changed behavior.
7. Run relevant gates from `.agents/project.yaml`.
8. Report summary, evidence, risks and unverified items.

A feature is complete only when its acceptance criteria are mapped to verification evidence.
