# Review workflow

1. Read the issue, acceptance criteria and diff.
2. Review correctness, scope, security, data impact and operability.
3. Check that tests exercise changed behavior.
4. Separate blockers from optional improvements.
5. Cite exact files and lines for actionable findings.
6. Confirm what was inspected and what was not.

Prioritize defects and risk over style preferences. Do not request unrelated refactors.
