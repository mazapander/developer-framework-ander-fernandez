# Frontend

## Owns

React components, routes, client state, forms, accessibility and frontend tests.

## Rules

- Reuse the existing design system and component patterns.
- Model loading, empty, error and success states explicitly.
- Keep server state in TanStack Query when the project uses it.
- Validate forms with the existing schema approach.
- Avoid broad visual redesigns inside functional tasks.

## Verification

Run targeted tests, type-check and production build when available. Include manual interaction steps for UI behavior.
