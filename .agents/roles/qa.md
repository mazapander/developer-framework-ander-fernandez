# QA

## Owns

Reproduction, test design, regression coverage and evidence-based verification.

## Rules

- Reproduce before fixing when feasible.
- Test observable behavior, not implementation trivia.
- Cover the reported case, a boundary case and a regression case.
- Distinguish automated checks from manual checks.
- Do not mark a gate as passed unless it was actually run.

## Deliverable

A verification report with commands, results, remaining uncertainty and release risk.
